For people who work with AI agents

From recorded AI work to work worth sharing.

Claude Code, GitHub Copilot CLI and OpenCode already record your sessions on your computer. Midden reads them and helps you turn what happened into findings, articles, tutorials, presentations and longer pieces, each pointing back to the records it came from.

Install Midden @VERSION@ Read the documentation

Free and open source under the MIT License, for Windows, macOS and Linux on x64 and Arm64.

For example

“Write a tutorial from the sessions where I set up the release pipeline.”

  • release-pipeline.mdThe tutorial, citing the session records it rests on
  • sources/Those records, collected into a collection you can verify
  • release-pipeline.htmlA rendered copy, when you ask for one

What a session only reports, such as checks that passed, is written up as reported, not as proven.

What it is

Three parts. Use one, or all three.

Core

The midden command lists, reads, searches and collects records from your sessions. It opens them read-only, never calls a model and makes no network connections.

The skills

Four skills for the agent you already use: Claude Code, GitHub Copilot CLI, or an agent that reads ~/.agents/skills. You ask for an outcome; they run midden and write files.

Install

One command, for your user account only.

The installer checks every download against the release's checksums and needs no administrator rights, Python, Go or Node.

The App, with Core and the skills

Windows, in PowerShell

irm https://xibodev.github.io/midden/install.ps1 | iex

macOS and Linux

curl -fsSL https://xibodev.github.io/midden/install.sh | sh

Midden starts and opens in your browser; choose Quit Midden in the page to stop it. Later, start it from the Start menu, your Applications folder or your application menu.

The skills for your agent, with Core

Windows, in PowerShell

& ([scriptblock]::Create((irm https://xibodev.github.io/midden/install.ps1))) -Mode bundle -Harness claude

macOS and Linux

curl -fsSL https://xibodev.github.io/midden/install.sh | sh -s -- --mode bundle --harness claude

Use claude, copilot or agents as the harness, or core as the mode for Core alone.

On macOS and Linux the commands are linked into ~/.local/bin, which must be on your PATH. Midden's programs are not code-signed: checksums show that files are intact, not who published them. Options, updates and removal

Privacy

Your sessions stay where they are.

Midden works on your computer. It sends nothing anywhere unless you connect a model to the App's assistant.

  • Core opens session stores read-only, never calls a model and has no network code.
  • With the skills, your agent reads session records like any other file and sends what it reads to its own model, as usual.
  • The App listens only on 127.0.0.1 and answers only pages opened with the key it prints at each start.
  • What you send to the App's assistant goes to the model provider you connect, and its web tools can reach the internet.
  • Midden sends no telemetry.
  • Core hides recognisable credentials in what it shows. That is not a privacy review: check what you share.
