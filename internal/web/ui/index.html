    Running

    At risk of failing to resume

    A transcript past ~680 MiB will not load: --resume times out and silently starts a new session. Harvest a brief and hand off instead.

    What the exhaust is made of

    Run midden scan --assay to measure.

    Connect optional tools

    Set up a local tool here; Midden keeps the settings it needs and never asks you to edit its source code or a manifest. Opening this page does not contact anything. Testing a connection is always an explicit action.

    Advanced configuration

    Existing plugin manifests still work. If Midden finds one for a built-in integration, it will offer to adopt it into these settings without overwriting it silently.

    Ask about your own history

    Answered from what midden already knows — the index, the assay, your nuggets and the findings. It never re-reads your transcripts, so a question costs about the same whether you have 50 sessions or 5,000.
