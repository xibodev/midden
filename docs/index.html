The 0.3 architecture preview separates core from the bundle. Older 0.2 releases use retired interfaces; read the migration guide before switching.

Core

Session data, without a model.

Locate, normalize, inspect, search, measure, collect and export recorded work from supported CLI stores. Stable source views and portable files make the results useful to people, scripts and agents.

Core does not run an AI, own an editorial workflow, or claim a valid reference proves a story true.

Agentic bundle

Methods the agent performs.

Investigation, article, presentation and long-form playbooks include supporting files and external-tool guidance. The host agent reasons, writes, runs tools, inspects results and revises with the operator.

The host already owns models, permissions and conversation. Midden does not add a second agent runtime.

Work stays inspectable.

Selected records, source references and assets form portable collections. Notes, outlines, drafts and output live in ordinary working directories. An empty project database is not proof that no draft exists.

Source stores are read-only during investigation. Credential filtering is not privacy clearance. Review intended disclosures; keep private source material out of public repositories.
