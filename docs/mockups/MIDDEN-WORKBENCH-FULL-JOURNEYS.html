Tools and settings

Capabilities are connected once, then appear where work needs them.

Plugins, tools, skills, viewers, and destinations have different responsibilities. Missing software is explained contextually instead of becoming an empty product tab.

Connects a runtime or service and declares setup, permissions, commands, and health.

One callable action such as render video, build diagram, or export notebook source.

Skill

Instructions and workflow knowledge the persistent agent can use.

Viewer
